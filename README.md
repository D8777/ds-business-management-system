# DS Business Management System — Pricing & Estimates

Internal pricing calculator for DS Automations. Builds customer estimates, hides private labor and software costs, and prepares email / PDF / CSV output.

Open `index.html` in a browser, or use the GitHub Pages URL after Pages is enabled.

## Refresh-safe save

The current working estimate autosaves in this browser. Refresh does not wipe in-progress work.

Saved estimate history also stays in this browser. Export CSV from **Saved Estimates** as a backup. Clearing browser data will remove saved estimates.

## Send an estimate

1. Enter the customer email.
2. Preview the customer estimate (internal costs stay hidden).
3. **Print / Save PDF** if you want a formal attachment.
4. **Email Estimate** opens your default mail app with the customer address, subject, and estimate text filled in. Attach the PDF if you saved one.

The app does not send email by itself.

## GitHub Pages

In the GitHub repo: **Settings → Pages → Deploy from a branch → `main` / `/ (root)`**.

The live URL will be:

`https://<your-github-username>.github.io/<repo-name>/`

Use the same browser when you return so autosaved estimates are still there.
